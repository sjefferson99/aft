Instance Global Settings

Sets the default theme for new users and public board viewers only. Existing users keep their current theme. Only system and global themes appear here.

Promoted themes become available to all users in the same way as system themes and can then be used as the instance default.

Demoting removes global visibility and returns the theme to user scope. Change the instance default first if the theme is currently in use as the global default.

# About AFT

Aim, Focus, Track: AFT is a self-hosted task board. Use it as simple Kanban boards, as Agile boards with done tracking, and with cards that appear on a schedule.

These docs ship with AFT, so the Docs page always matches the version you have installed and works without internet access.

- [User guide](user-guide.md): boards, columns, cards, scheduling and your own preferences
- [Administration](administration.md): installing updates, configuration, backups and access control
- API reference: open **API Docs** from the user menu in the header for the interactive Swagger page

## Open Source

AFT is open source software, available on GitHub: <https://github.com/sjefferson99/aft>

Contributions, bug reports and feature requests are welcome. Check the [issues list](https://github.com/sjefferson99/aft/issues) first in case yours has already been raised, and see the [releases page](https://github.com/sjefferson99/aft/releases) for what's new.

# Security Policy

## Reporting a security problem

Please don't report security problems in public issues.

[Report it privately on GitHub](https://github.com/sjefferson99/aft/security/advisories/new) instead, so it can be fixed before the details are public. You'll need a GitHub account.

Please include:

- What the problem is and what an attacker could do with it.
- Steps to reproduce it.
- The AFT version you tested.

## Supported versions

Security fixes go into the latest release, so please update to it before reporting.
